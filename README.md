# DSA 8670 — GitHub Practice Repository

This is your personal practice repository for DSA 8670. You created it from the course
template, and it belongs to you. Nothing you do here affects anyone else's copy.

You will use it in **Week 5** to practice:

- GitHub fundamentals (repositories, commits, branches, pull requests)
- Creating and closing Issues
- Linking Issues, commits, and Pull Requests so your work is traceable

Full instructions: **[Week 5 – GitHub Foundations](./week5.md)**

---

## Learning Goals

By the end of Week 5, you should be able to:

- Clone and manage a repository with GitHub Desktop.
- Make local changes, commit with clear messages, and push to GitHub.
- Create a branch, open a Pull Request, and merge it.
- Create an Issue and reference it from a commit or PR (e.g., `Closes #3`).

---

## Prerequisites

- A GitHub account with your Clemson email verified (Setup Assignment 1).

## Getting Started

1. Open **GitHub Desktop** and choose **File → Clone repository**.
2. On the **GitHub.com** tab, pick your `dsa8670-<yourusername>` repository and clone it.
3. Open [week5.md](./week5.md) and work through it in order.
